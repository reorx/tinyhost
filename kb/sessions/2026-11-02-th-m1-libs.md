## 实现说明

### 初始化与基础类型

module：`github.com/reorx/tinyhost`；SQLite：`modernc.org/sqlite v1.61.1`。根 `.gitignore` 已有 tmp/dist/data 规则，原样保留。Makefile 的 build 目前编译所有库，后续加 cmd 时可扩为两个二进制产物。

`internal/version.Version` 默认 `dev`，可由 `-ldflags '-X github.com/reorx/tinyhost/internal/version.Version=...'` 注入。

`token.New() string` 生成 `th_` + 43 位 base64url，`Hash(string) string` 返回 SHA-256 hex，`Equal(string, string) bool` 常量时间比较。

`slug.Valid(string) bool` 包含保留字校验；`ParseSegment(string) (string, int, error)` 的无版本返回 0，显式版本必须大于 0 且不能溢出 int。

### blob 接口

- `New(dataDir string) (*Store, error)`：创建 dataDir/blobs 和 dataDir/tmp。
- `(*Store).Put(io.Reader) (hash string, size int64, err error)`：流式哈希、临时写入及 fsync、原子发布或复用并刷新 mtime；错误时清理临时文件。
- `Open(hash string) (*os.File, error)`：打开只读文件，调用者关闭。
- `Remove(hash string) error`：删除文件块；不存在时返回文件系统错误。
- `Walk(func(hash string, info os.FileInfo) error) error`：遍历合法哈希命名的普通文件，提供 GC 所需的 size/mtime；不跟随符号链接。

哈希必须为 64 字节小写 hex，Open/Remove 不允许任意路径。tmp 和 blobs 必须在支持硬链接的同一文件系统中（默认数据目录布局满足）。

### bundle 接口与服务端接法

- `Pack(path string, options ...Options) (tmpfile string, summary Summary, err error)`：默认 deploy 模式要求 index.html；`Options{Data:true}` 允许无 index 的数据包。调用者必须删除返回的临时文件。
- `Unpack(r io.Reader, limits Limits, sink func(path string, content io.Reader) error) (Summary, error)`：默认 50MiB/1000 条目；deploy 应传 `Limits{RequireIndex:true}`。只有整个 Unpack 成功后才提交元数据。
- `Manifest`：`App string`、`Title string`、`Data map[string]string`；未知 JSON 字段允许但不保存；root 必须是 JSON 对象，最大 64KiB。
- `Summary`：`Files int`、`Size int64` 只计入进入层的内容；另有 Manifest、Skipped、Warnings。
- `Limits`：`MaxSize int64`、`MaxFiles int`、`RequireIndex bool`；零值使用默认限制。
- `Options`：`Data bool`、`Limits Limits`。
- `ErrTooLarge`：可用 errors.Is 匹配，供 server 映射 too_large。

打包不跟随链接，记录警告；排除任意层级的 node_modules、点文件（.well-known 除外）。根 tinyhost.json 单独进入 tar，解包解析后不交给 sink，因此不入层也不能作为网页提供。

解包拒绝危险路径、重复路径和所有非普通文件类型（目录条目忽略），隐藏文件静默跳过并记录。总文件 payload 限额之外，tar metadata 与尾部的解压预算为 `MaxSize + MaxFiles*2048 + 1MiB`，防止 PAX 头及 tar EOF 后的解压炸弹，并验证 gzip CRC。

服务端上传数据时，sink 收到的路径相对于覆盖目录；需先规范化目标 dir，再将 `dir + path` 写入 `Layer.Files`。store 不会替调用者重复加前缀。blob 写入在 SQL 事务之外，未提交文件块由后续 GC 处理。

### store 函数清单

以下方法接收者均为 `*store.Store`；app 参数是 **App.ID，不是 slug**。时间字段统一 Unix 秒，nullable 字段用指针表示。`Layer.Files []File` 为上传结果，每个 File 有 Path、Blob、Size；层 ID、文件数和总大小由事务计算生成，忽略调用方传入的层统计值。

| 签名 | 用途 |
|---|---|
| `Open(path string) (*Store, error)` | 打开数据库并原子迁移；WAL、busy_timeout=5000、foreign_keys=1、单连接、immediate 事务；拒绝未来 schema。 |
| `Close() error` | 关闭连接。 |
| `CreateClient(name, hash string, expiresAt *int64) (*Client, error)` | 写入客户端及 token 哈希，生成 c_ ID；Meta 默认为 `{}`。 |
| `ClientByTokenHash(hash string) (*Client, error)` | 查询客户端；不存在返回 nil,nil，撤销和过期记录仍返回，由 handler 做鉴权。 |
| `TouchClient(client, ip string) error` | 更新 last_used_at/IP，距离上次至少 60 秒才写。 |
| `RevokeClient(client string) error` | 标记撤销；重复调用不改变原撤销时间。 |
| `CreateApp(slug, title, visibility, by string) (*App, error)` | 创建空 App，生成 a_ ID；slug 全局唯一，visibility 由 CHECK 约束。 |
| `AppBySlug(slug string) (*App, error)` | 包含回收站，便于 slug_taken 响应；不存在返回 nil,nil。 |
| `ListApps() ([]*App, error)` | 只列未删除 App，更新时间降序、slug 排序。 |
| `SoftDeleteApp(app string) error` | 标记 deleted_at，保留 slug；创建者权限由 handler 校验。 |
| `CommitAppVersion(app string, layer *Layer, manifest bundle.Manifest, msg, by string, promote bool) (*Version, error)` | 在一个事务中写层/文件、分配版本号、沿用主入口覆盖层、更新标题和可选主入口。 |
| `CommitDataVersion(app, dir string, layer *Layer, msg, by string) (*Version, error)` | 基于主入口替换覆盖目录并自动 promote；nil layer 撤掉目录；空 App 自动创建零文件 base。 |
| `Promote(app string, n int) error` | 主入口切到现存正整数版本，不生成新版本。 |
| `Versions(app string) ([]*Version, error)` | 返回版本元数据，编号降序；不加载每个版本的覆盖层。 |
| `ResolveVersion(app string, n int) (*Version, error)` | 0 表示主入口；事务内解析版本和有序覆盖层，已删除 App 拒绝访问。 |
| `LookupFile(layer, path string) (*File, error)` | 单层精确查询；无文件返回 nil,nil。 |
| `LookupVersionFile(v *Version, path string) (*File, error)` | 先选择覆盖层或 base 再查精确路径；覆盖层缺文件绝不回落 base。 |
| `AddEvent(actor, action, app, detail string) error` | 记录审计事件；detail 由调用方提供 JSON 字符串。 |
| `PruneDataVersions(keep int) error` | 每个 App 保留最新 keep 个 data 版本，另外保护旧的主入口版本；App 包版本不删。 |
| `PurgeTrash(before time.Time) error` | 删除 deleted_at 严格早于阈值的 App，级联删除版本/覆盖引用并释放 slug。 |
| `OrphanLayers() ([]*Layer, error)` | 列出无版本/base 或 overlay 引用的层及统计值。 |
| `DeleteOrphanLayer(id string) error` | 删除前再次原子检查引用，级联删除 layer_files；仍被引用则不操作。 |
| `ReferencedBlobs() (map[string]bool, error)` | 返回所有 layer_files 中仍存在的文件块哈希集合。 |
| `NormalizeOverlayDir(dir string) (string, error)` | 包级函数；拒绝根、空段、点开头段、反斜杠等，返回末尾带 `/` 的相对路径。 |

`ErrAppNotFound`、`ErrVersionNotFound`、`ErrOverlayConflict`、`ErrOverlayNotFound` 可用 errors.Is 匹配。冲突错误文本带已有目录；完整现有目录可由 ResolveVersion 返回。唯一性错误保留 SQLite 错误，slug_taken 的创建者/时间/回收站信息用 AppBySlug 获取。

发布方法返回完整新版本（含覆盖层），并保证失败不会消耗编号、移动主入口或留下部分层。`promote=false` 从未发布的 App 仍可以没有主入口。重新发布使用主入口而非最大编号版本；覆盖层的 pushed_by/pushed_at 沿用原始来源。

GC 调用顺序：PruneDataVersions → PurgeTrash → OrphanLayers/DeleteOrphanLayer → ReferencedBlobs → blob.Walk。文件块是否早于一小时、调度与日志都由 server 负责。**ReferencedBlobs 必须在删除孤立层之后获取。**

## AGENTS.md 建议

可由协调者直接粘贴进代码地图：

- `internal/version`：Version 变量供 -ldflags -X 注入；Go 由 mise 管理，当前 1.27.3。
- `internal/token`、`internal/slug`：凭证生成/哈希及 slug、@vN 校验。
- `internal/blob`：内容寻址存储，Put 完成后原子发布；复用刷新 mtime；tmp 与 blobs 需支持同文件系统硬链接。
- `internal/bundle`：目录/单文件 tar.gz 打包与流式安全解包；根 tinyhost.json 只作元数据。Pack 的临时文件归调用者清理。
- `internal/store`：嵌入 schema.sql，user_version 迁移；CommitAppVersion/CommitDataVersion 原子写层、版本、主入口。参数 app 使用 ID；数据层路径必须预先加上规范化覆盖目录前缀。
- `LookupVersionFile` 不在覆盖层缺文件时回落 base；HTTP 的补全和 404 策略由 server 实现。
