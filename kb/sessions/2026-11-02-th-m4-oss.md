## 验证与证据

- `setup.py`、`update-demo.py`：独立本地数据库与虚构数据生成；`demo/` 保存示例页面。都位于任务证据目录，不提交。
- `capture.py`、`screenshot-measurements.json`：最终截图及布局和体积记录；归档同时保存全部 README 图片。
- `check-preview.py`、`check-preview.js`、`preview-checks.json`、`preview-check.log`：真实浏览器读取经 GitHub Markdown API 渲染的预览，核对宽度、主题与图片；并验证 shell 语法和本地引用。
- 归档含 `readme-1280-light.png`、`readme-1280-dark.png` 全页图、对应双列图细节和手机看板图。
- `demo-design-check.json`：示例的机械设计检查；发现的小字号在最终示例中已调为至少 12px。独立只读评审核对最终源码和截图，结论为 `ship`。
- `cleanup.py`：删除本地会话、撤销演示 token、拒绝待批准申请，删除临时明文；本地服务正常收到 TERM 后退出。
- `mac-dev-cleanup --only browser --min-age 2`：在本任务浏览器关闭后运行，没有需清理的会话；预览进程不受影响。
- 文档及截图任务没有修改 Go 代码，没有运行格式化器、样式 lint、全量 Go 测试或本机 Docker。服务端由当前代码本地构建，仅供截图。

外部说明核对使用 [Caddy reverse_proxy 文档](https://caddyserver.com/docs/caddyfile/directives/reverse_proxy#defaults) 与 [GitHub private reporting 文档](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/report-privately)，抓取副本只留任务证据目录。
