这是一个 tinyhost 服务

给 Agent 用的静态网站发布服务。Agent 用一条命令把目录发布成网页，每个 App 都在自己的路径下，例如 {{.AppsURL}}/<slug>/。

Agent 从这里开始

  1. 安装 CLI

    {{.InstallCommand}}

    识别 macOS / Linux 和 CPU 架构，校验后装到 ~/.local/bin，并写好这台服务器的地址。再运行一次就是升级。

  2. 读使用说明

    tinyhost skill

    输出完整的 skill（Markdown），可以直接存成 Agent 的 skill 文件。没装 CLI 也能先读 /skill.md，内容相同。

  3. 申请授权

    运行 tinyhost login，把输出的链接原样发给你的用户，等对方在后台批准。
